# 🏫 NIS Portal API

Backend for a school portal built around how Nazarbayev Intellectual Schools actually work: specialised classes, a weekly schedule, and **criteria-based assessment** (formative assessment, SOR and SOCh summative assessments) with an automatic report card per student.

## Features

- **Teachers, classes and students**: full CRUD, with students attached to their class
- **Schedule**: subjects and lesson slots
- **Assessment**: tasks (FO / SOR / SOCh), grades, and `GET /report-card/{student_id}` that assembles a student's results
- **Announcements**: school news feed
- Async SQLAlchemy 2.0 with `asyncpg`, Pydantic v2 schemas, a generic CRUD base class
- Interactive docs generated by FastAPI at `/docs`

## API overview

All routes live under `/api/v1`.

| Resource | Endpoints |
|---|---|
| `/teachers` | `GET` list · `POST` create · `GET/PATCH/DELETE /{id}` |
| `/classes` | `GET` list · `POST` create · `GET/PATCH/DELETE /{id}` |
| `/students` | `GET` list · `POST` create · `GET/PATCH/DELETE /{id}` |
| `/schedule/subjects` | `GET` · `POST` · `GET/PATCH/DELETE /{id}` |
| `/schedule/items` | `GET` · `POST` · `GET/PATCH/DELETE /{id}` |
| `/assessments/tasks` | `GET` · `POST` · `GET/PATCH/DELETE /{id}` |
| `/assessments/grades` | `POST` · `PATCH /{id}` |
| `/assessments/report-card/{student_id}` | `GET` |
| `/announcements` | `GET` · `POST` · `GET/PATCH/DELETE /{id}` |

## Project structure

```
app/
├── api/v1/endpoints/   # route handlers per resource
├── core/               # settings, database engine, security helpers
├── crud/               # data access (generic base + one module per model)
├── models/             # SQLAlchemy models
├── schemas/            # Pydantic request/response schemas
└── main.py             # app factory, CORS, lifespan (creates tables on start)
tests/test_api.py       # health check + full portal workflow test
```

## Run it

**With Docker (PostgreSQL included):**

```bash
docker compose up --build
```

Open http://localhost:8000/docs.

**Locally:**

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
cp .env.example .env            # then set DATABASE_URL
uvicorn app.main:app --reload
```

**Tests:**

```bash
pytest
```
